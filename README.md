# Relay

An independent game policy built on the TypeScript foundation of [Henka](https://github.com/raunak-choudhary/henka/tree/155c0edf92866fa55aadc79bc6521ecf6126f94c). The upstream vector helpers, terrain decoder and organizer-derived mechfight protocol adapter are in src. Their license is preserved in LICENSE.upstream. All gameplay decisions live in the new pilot.ts. Run with Node 24 or build the root Dockerfile.
